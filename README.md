# CRUD-clientes---JDBC-MySQL
## Learning how to connect Databases with Java

<h2>Objective:</h2>
I have been studying JDBC, which is a driver that uses an API to connect databases with Java, enabling data storage in a more proper and secure way.
Taking advantage of this new knowledge, I created a simple client CRUD to apply what I've learned.<br>

<h2>Technologies:</h2>
<ul>
  <li>Java</li>
  <li>Maven</li>
  <li>JDBC</li>
  <li>MySQL</li>
</ul>
